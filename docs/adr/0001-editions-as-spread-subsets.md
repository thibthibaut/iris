# Editions are subsets of one master Spread sequence

There is a single album layout (the `ours` Edition). Every other Edition is that same sequence of Spreads with the Group Spreads of the other Groups removed: no per-Edition layout run, no per-Edition photo variants in the same position, no per-Edition page targets. We chose this so that the four books stay "the same classic wedding album", every edit is made once, and an Edition costs nothing to keep in sync. The price is that per-Edition emphasis is limited to Group Spreads. Person Quotas act on the whole album.

## Considered Options

- **Separate layout run per Edition** (the first plan: 48 vs 32 pages, core spreads dropped to fit): rejected, because every edit would have to be repeated or reconciled across four layouts.
- **Variant Spreads** (one position whose content changes per Edition): rejected. Placing the Group Spreads next to each other gives the same reading experience in a family Edition without a new concept.
- **Tagging Spreads core/family by the majority of faces**: rejected. A Spread's status is decided when it is generated (or by the user), never re-derived from faces.
